Chemistry English Lab — Study Edition (v2)

How to use:
1. Unzip this folder.
2. Open index.html in a modern browser.
3. Search vocabulary, choose chapters, practice Quiz modes, use flashcards.
4. Learning progress is stored locally in the browser; it does not sync between devices.

Content note:
The 1,051 entries are a supplementary study vocabulary aligned to the 24 chapter topics of Chemistry: The Central Science, 15th Global Edition. Some example sentences are original study aids, not quotations from the textbook. This is not a complete page-by-page extraction of the textbook. Confirmed available textbook splits cover pages 1–300 and 1201–1835; missing middle ranges still need to be processed.
